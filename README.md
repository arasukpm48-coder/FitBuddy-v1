# 💪 FitBuddy – AI Fitness Plan Generator using Gemini Models

FitBuddy creates a personalized **7-day workout plan** with Google Gemini, adds a
**nutrition/recovery tip**, lets you give **feedback** to update the plan, and stores
everything in **SQLite**.

> ⚠️ FitBuddy provides general fitness and wellness information generated by AI. It is not a
> substitute for professional medical advice. Consult a qualified professional if you have
> health conditions, injuries, or concerns.

**Tech stack:** Python, FastAPI, Uvicorn, Jinja2, HTML/CSS, SQLite, SQLAlchemy, Pydantic,
Google Gemini (`google-genai` SDK).

---

## 1. Install Python
1. Go to https://www.python.org/downloads/ and download Python 3.10 or newer.
2. Run the installer and **tick "Add Python to PATH"**.
3. Check it worked (Command Prompt):
   ```
   python --version
   ```

## 2. Open the FitBuddy folder in VS Code
Open VS Code → **File → Open Folder** → choose the `FitBuddy` folder.
Then open the terminal: **Terminal → New Terminal**.

## 3. Create a virtual environment
```
python -m venv fitbuddy-env
```

## 4. Activate it (Windows)
```
fitbuddy-env\Scripts\activate
```
You should see `(fitbuddy-env)` at the start of the line.
(If PowerShell blocks it, run `Set-ExecutionPolicy -Scope Process Bypass` first, or use Command Prompt.)

## 5. Install requirements
```
pip install -r requirements.txt
```

## 6. Create the `.env` file
```
copy .env.example .env
```

## 7. Add your Gemini API key
1. Go to https://aistudio.google.com/apikey and sign in.
2. Click **Create API key** and copy it.
3. Open `.env` and change it to:
   ```
   GOOGLE_API_KEY=paste_your_real_key_here
   ```
Never share this key or upload `.env` to GitHub (it is already in `.gitignore`).

## 8. Run the application
```
uvicorn app.main:app --reload
```
Or double-click `run.bat`. (`uvicorn app:app --reload` also works.)

## 9. Open the browser
http://127.0.0.1:8000

## 10. Test the application
- Home page opens with the form.
- Fill it in and click **Generate My Workout**.
- Open http://127.0.0.1:8000/view-all-users to see stored data.

## 11. Open /docs
http://127.0.0.1:8000/docs (automatic Swagger documentation).

## 12. How to use workout generation
Enter User ID, Name, Age, Weight (kg), Fitness Goal and Intensity, then click
**Generate My Workout**. Wait 10–30 seconds. You get 7 day cards and a nutrition tip.
Using the same User ID again replaces that user's plan.

## 13. How to submit feedback
On the result page, type feedback like "Add more cardio" and click **Update My Workout**.
The updated plan is shown and saved. The original plan is kept too.

## 14. How to view all users
Open http://127.0.0.1:8000/view-all-users (or click **All Users** in the menu).

## Which Gemini models are used?
The original project used Gemini 1.5 Pro and Gemini Flash. Those older models have been
retired, so FitBuddy keeps the **same roles** with Google's current "latest" aliases:

| Role | File | Model (default) | Why |
|------|------|-----------------|-----|
| Workout generation + update | `gemini_generator.py`, `updated_plan.py` | `gemini-pro-latest` | Strongest model, best for a long structured 7-day plan |
| Nutrition/recovery tip | `gemini_flash_generator.py` | `gemini-flash-latest` | Fast and cheap, ideal for a short tip |

The `-latest` names always point to Google's newest model of that type, so the code
keeps working when models change. To pick a specific model, set `GEMINI_PRO_MODEL` /
`GEMINI_FLASH_MODEL` in `.env` (see https://ai.google.dev/gemini-api/docs/models).

## Project architecture (for SkillWallet)
```
Browser → FastAPI (app/main.py) → Routes (app/routes.py)
                                     ├── Pydantic validation (schemas.py)
                                     ├── Gemini Pro  (gemini_generator.py, updated_plan.py)
                                     ├── Gemini Flash (gemini_flash_generator.py)
                                     ├── SQLite via SQLAlchemy (database.py, models.py)
                                     └── Jinja2 templates (templates/*.html + static/style.css)
```
- `app/main.py` = **application entry point** (the "app.py" of SkillWallet: creates the app,
  mounts static files, adds routes, creates the database).
- `app/routes.py` = **routing and request processing** (forms, validation, Gemini calls, saving).
- `app/__init__.py` exposes `app`, so `uvicorn app:app --reload` also works.

## Common problems
| Problem | Fix |
|---------|-----|
| `'python' is not recognized` | Reinstall Python and tick "Add to PATH" |
| `ModuleNotFoundError` | Activate the virtual environment, then `pip install -r requirements.txt` |
| "Gemini API key is missing" | Check `.env` exists and contains `GOOGLE_API_KEY=...`, then restart the server |
| "API key was rejected" | Create a new key at aistudio.google.com/apikey |
| "API limit was reached" | Wait a minute (free keys have limits); or set `GEMINI_PRO_MODEL` to a Flash model |
| "model name was not found" | Check model names on the Gemini models page and update `.env` |
| Port 8000 busy | `uvicorn app.main:app --reload --port 8001` |
